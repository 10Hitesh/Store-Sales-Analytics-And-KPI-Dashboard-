# Store-Sales-Analytics-And-KPI-Dashboard-

## 📊 Project Overview

This project analyzes **retail sales data** to identify sales trends, regional performance, product performance, and key business metrics.

The project uses **Excel for initial data preparation, SQL for data cleaning and analysis, and Power BI for interactive dashboard development**.

The objective is to transform raw retail data into meaningful **business insights and KPI reports** that can support data-driven decision-making.

---

## 🎯 Project Objectives

* Analyze overall **retail sales performance**
* Track important **sales KPIs**
* Compare performance across **regions, stores, and products**
* Identify **sales trends and patterns**
* Analyze **customer and product behavior**
* Create an interactive **Power BI dashboard**
* Use SQL to perform data transformation and analytical queries

---

## 🛠️ Tools & Technologies

* **Excel** – Initial data cleaning and preparation
* **SQL / SQL Server Management Studio (SSMS)** – Data cleaning, transformation, aggregation, and analysis
* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data transformation and preparation
* **DAX** – KPI calculations and measures

---

## 🔄 Project Workflow

### 1. Data Collection & Preparation

The raw retail sales dataset was initially available in Excel.

Basic data preparation was performed to:

* Identify missing/null values
* Check duplicate records
* Standardize data
* Verify order and customer information
* Prepare the dataset for SQL analysis

### 2. SQL Data Analysis

The cleaned dataset was imported into **SQL Server** for further analysis.

SQL was used for:

* Data filtering
* Data aggregation
* Grouping and sorting
* Sales calculations
* Regional analysis
* Product-level analysis
* Store performance analysis
* Joining related datasets

Key SQL concepts used:

```sql
SELECT
WHERE
GROUP BY
ORDER BY
SUM()
COUNT()
AVG()
JOIN
```

### 3. Power BI Dashboard

The processed data was connected to **Power BI** to create an interactive dashboard.

The dashboard provides insights into:

* Total Sales
* Regional Sales
* Product Performance
* Store Performance
* Sales Trends
* Customer Behavior
* Key Performance Indicators (KPIs)

Interactive filters and visualizations allow users to explore the data from different perspectives.
